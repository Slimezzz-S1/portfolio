# Portfolio - Scripts
This is a helper script that generates data for portfolio

### How it works

The scripts takes data from `./scripts/input_folder` like github graphql, leetcode graphql, and monkeytype csv results, then sends out the result from these files into `./src/assets/data/*`.

### Supports
1. Github GraphQL
2. Leetcode GraphQL
3. Monkeytype Results CSV
